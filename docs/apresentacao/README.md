# Material de Apresentação — IFConnect

Documentação de apoio para demonstração ao vivo e arguição técnica do projeto.

- [`guia-do-codigo.md`](./guia-do-codigo.md) — mapa rápido do repositório, fluxos de indexação e consulta, atalhos para cada módulo e trechos prontos para mostrar na tela.
- [`roteiro.md`](./roteiro.md) — linha do tempo de 11 minutos, 5 perguntas da demonstração, respostas para perguntas da banca, plano B e glossário.

## Como abrir os links de código

- **No VS Code:** abra a prévia Markdown com `Ctrl+Shift+V` e clique nos links (ou use `Ctrl+clique` diretamente no editor).
- **No GitHub:** clique em qualquer link para abrir o arquivo já posicionado nas linhas indicadas.

## Verificação automática dos links

Na pasta `backend`, execute `npm run guia:verificar` (no PowerShell com política restrita, use `npm.cmd run guia:verificar`).
